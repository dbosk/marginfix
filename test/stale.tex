% Test of records that a page no longer needs (\marginnoteoverflow{break}).
%
% Two paragraphs dense with long notes in the margin, the second further on.
% A build from no .aux file records, in the same run, the first note that
% doesn't fit on each page, each from the layout before any page ends
% early.  Once the first paragraph's page ends early, the text after it
% moves, and the second record can end a page a few lines from its top,
% where its note would fit.  \stalecase chooses:
%
%   stale    memoir, its footnotes in the margin: the second record must be
%            retired, so that no page ends early for a note that fits, and
%            the page fills;
%   article  the same in the article class, with \marginpar;
%   twoside  stale, two-sided, where the notes of even pages have the other
%            margin;
%   twocol   the same text in two columns, with \staletwocolB lines of space
%            before the second paragraph;
%   needed   memoir, with more space before the first paragraph: both
%            records are needed (each page that ends early is full of
%            notes), and must stay, though one page is less than half full;
%   linemate stale, with a long note called out on the same line just
%            before the note of the second record: the page has room for
%            that note alone, but not for both, which come to it together,
%            so the record is needed and must not be retired, not even
%            once.
%
% \stalepriority, if defined, is a \marginnotepriority mode, and \stalelimit a
% \marginnoteyieldlimit in lines: the stale record must be retired under each
% of them too, and under a limit its page must not be capped for it.
%
% \staleltlen, if defined, is the length of a deferrable note called out at the
% note H, in sixes of sentences: with \stalepriority defer or split, the note
% J still fits on the stale page, since the deferrable note gives way to it.
%
% \stalefront, if defined, is the file with the first paragraph, instead of
% the text below.  test/stale-front-a.tex has the same paragraph, and
% test/stale-front-b.tex has no notes in it: going from one to the other is
% an edit that keeps the keys of the notes in this file.
%
% \stalegrow, if defined, is added to the text of the note J, and \stalegrowd
% to that of the note G, whose page ends early for it in the case stale.
%
% \staleolder, if defined, undefines what marginfix's .aux records use and
% an older version doesn't know, as such a version would read the file.
%
% \stalelie, if defined, is the key of a note whose height is taken to be 1pt
% in every run, whatever the .aux file says, so that the check of its page is
% wrong every time: the runs must settle all the same, with the page ending
% early for the note and a warning.
%
% test/stalecheck.sh runs the cases and checks them.
